> ##  My Projects
>>> ### ZAP - Zippy Asset Packager
>>> **Zap** is a lightweight command-line package manager written in Python.
>>>
>>>[Open on github](https://github.com/Bkner3/zap)
>>>
>>>#### Why I created ZAP
>>> ---
>>>One day, I had a great idea: create a Linux distro based on Arch Linux, similar to EndeavourOS, using the Arch Linux repositories and my own repositories. (I didn't actually start the distro project.)
>>>
>>>While thinking about this, I learned the hard truth: creating and maintaining your own package repository is a lot of work, and you have to do almost everything yourself.
>>>
>>>That gave me another idea: creating my own package manager. I took some inspiration from Homebrew on macOS.
>>>
>>>So I started ZAP to create a package manager that is simple for everyone to use, with tools for creating your own repositories (I haven't worked on those yet). As they say in my native language (Portuguese), "com uma mão nas costas" (with one hand behind my back).
>>> #### What ZAP can do
>>> ---
>>>ZAP can install, update, remove, and download packages.
>>>
>>>It verifies packages using SHA-256, and the repository uses JSON for its index.
>>>
>>> #### What I have learned

>>>
>>> I also learned more about Python and JSON, because ZAP is the project I am using to learn how to program and write clean code.
